# Resources

Where this brain comes from, and where to go deeper. All public.

## Open-source repositories

The community skill packs and prompt projects this material was redrafted and structured from:

- [wowsergei/hormozi-gtm](https://github.com/wowsergei/hormozi-gtm) - the $100M trilogy (Offers, Leads, Money Models) distilled into an AI-ready GTM playbook.
- [Wrenbjor/Hormozi-Marketing-Agent-Skills](https://github.com/Wrenbjor/Hormozi-Marketing-Agent-Skills) - six agent skills covering the complete Hormozi business and marketing playbook, one per phase.
- [zacker-tech/hormozi-skills](https://github.com/zacker-tech/hormozi-skills) - Claude Code skills based on the $100M trilogy.
- [alexsmedile/hormozi-skills](https://github.com/alexsmedile/hormozi-skills) - turns a business idea into a complete sellable offer using Hormozi frameworks (MIT).
- [genshin-hermes/hormozi-100m-skill](https://github.com/genshin-hermes/hormozi-100m-skill) - portable skill extracted from the 13-book series.
- [rediumvex/hormozi-sales-cold-outreach-claude](https://github.com/rediumvex/hormozi-sales-cold-outreach-claude) - three Claude Code skills that turn a cold list into booked calls.
- [wombyz/HormoziGPT](https://github.com/wombyz/HormoziGPT) - chatbot that simulates Alex Hormozi conversations for business advice.
